# pp2-veins: Сегментация сосудов глазного дна

## 1. Цель модели

### 1.1. Описание задачи

Проект `pp2-veins` предназначен для автоматической семантической сегментации сосудов глазного дна на изображениях фундус-камеры. Модель решает задачу многоклассовой пиксельной классификации с выделением артерий, вен, капилляров и зон пересечения сосудов (A/V crossovers).

### 1.2. Бизнес-контекст

Автоматическая сегментация и классификация артериовенозного русла глазного дна является критически важным этапом в системах компьютерной диагностики:

- **Скрининг диабетической ретинопатии:** количественная оценка калибра артерий и вен (Arteriovenous Ratio, AVR) является ранним маркером микроангиопатии.
- **Мониторинг артериальной гипертензии:** сужение артериол и расширение венулов коррелируют с тяжестью гипертонической ретинопатии.
- **Риск-стратификация сердечно-сосудистых заболеваний:** морфометрия сосудов глазного дна используется как неинвазивный суррогатный маркер состояния системной микроциркуляции.
- **Доклиническая диагностика:** выявление микроаневризм, неоваскуляризации и окклюзий на ранних стадиях.

### 1.3. Целевой пользователь

Система ориентирована на офтальмологов и специалистов по медицинской визуализации в качестве вспомогательного инструмента при скрининговом анализе фундус-снимков.

## 2. Метрики

### 2.1. Основные метрики

| Метрика | Описание |
|---------|----------|
| **Dice** | Коэффициент перекрытия предсказания и Ground Truth |
| **IoU** | Коэффициент пересечения-объединения |
| **Accuracy** | Общая точность (доля верно классифицированных пикселей среди всех) |
| **Precision** | Точность (доля верно предсказанных пикселей сосуда среди всех предсказанных) | 
| **Recall** | Полнота (доля обнаруженных пикселей сосуда) | 

### 2.2. Детализация по классам

Метрики вычисляются отдельно для каждого из 5 классов:

| Класс | Метка | Описание |
|-------|-----|----------|
| Фон | 0 | Пиксели, не относящиеся к сосудам |
| Артерия | 1 | Артериальные сосуды |
| Вена | 2 | Венозные сосуды |
| Капилляр | 3 | Мелкие сосуды и капиллярная сеть |
| Пересечение | 4 | Зоны артериовенозного пересечения (A/V crossover) |

### 2.3. Протокол оценки

- **Кросс-валидация:** 3-фолдовая (3-Fold Cross-Validation) для получения доверительных интервалов.
- **Агрегация:** Среднее ± стандартное отклонение по фолдам.
- **Статистическая значимость:** Вычисление 95% доверительных интервалов и p-value для сравнения моделей.
- **Внешняя валидация:** Оценка на независимых датасетах (`external_datasets/`) без дообучения.

## 3. Ограничения

### 3.1. Область применимости

Модель предназначена **исключительно** для анализа:
- Цветных фундус-снимков, полученных стандартными фундус-камерами.
- Изображений с полем обзора 30°–50°.
- Разрешения входного изображения после ресайза: 512×512 пикселей.

### 3.2. Известные ограничения

| Ограничение | Описание |
|-------------|----------|
| **Качество снимка** | Модель не обеспечивает достоверной сегментации при выраженных артефактах: бликах, низкой контрастности, сильной катаракте и т.п. |
| **Патологии** | Модель не была валидирована на изображениях с выраженными патологиями, которые могут перекрывать сосудистое русло. |
| **Оптические когерентные томограммы (ОКТ/ОКТА)** | Модель неприменима к данным ОКТ-ангиографии. |
| **Неклинические данные** | Модель не предназначена для анализа изображений, полученных на нестандартных устройствах (смартфоны и др.). |

### 3.3. Технические ограничения

- **Вычислительные ресурсы:** Обучение требует GPU с ≥ 8 ГБ видеопамяти (рекомендуется ≥ 12 ГБ для энкодера EfficientNet-B3).
- **Инференс:** Одно изображение 512×512 обрабатывается за ~50 мс на GPU NVIDIA A100. На CPU время увеличивается до ~2–4 секунд.

### 3.4. Клинические ограничения

- Модель **не выдаёт клинический диагноз**. Результат сегментации является вспомогательной визуализацией для последующей интерпретации врачом.
- Автоматическая классификация артерия/вена может быть ошибочной в зонах пересечения.
- Количественные измерения (калибр, AVR), полученные на выходе модели, требуют дополнительной верификации.

## 4. Bias/Fairness анализ

### 4.1. Источники потенциального смещения

| Фактор | Потенциальный риск | Меры митигации |
|--------|--------------------|-----------------|
| **Пигментация глазного дна** | Различия в контрастности сосудов у пациентов с разной степенью пигментации сетчатки | Включение в обучающую выборку изображений с различной пигментацией; аугментации цвета и контраста |
| **Возраст** | У пожилых пациентов сосуды более извиты, истончены, могут присутствовать артериосклеротические изменения | Стратифицированная выборка по возрастным группам при валидации |
| **Пол** | Незначительные различия в калибре сосудов | Контроль баланса классов при стратификации фолдов |
| **Тип фундус-камеры** | Различия в цветопередаче и разрешении между моделями оборудования | Внешняя валидация на датасетах, полученных на различных камерах |
| **Качество мидриаза** | Изображения с узким зрачком имеют затемнённые периферические зоны | Исключение неинформативных снимков на этапе предобработки |

### 4.2. Проведённый анализ

- **Кросс-валидация:** 3-фолдовая схема со стратификацией по пациенту (один пациент не попадает одновременно в обучающую и валидационную выборки).
- **Анализ ошибок:** Визуализация предсказаний для подгрупп с различной пигментацией.
- **Доверительные интервалы:** Вычисление 95% ДИ для каждой метрики с целью выявления статистически значимых различий между подгруппами.

### 4.3. Рекомендации по снижению смещения

1. Расширение обучающей выборки за счёт мультицентровых данных.
2. Проведение подгруппового анализа по пигментации, возрасту и типу оборудования.
3. Документирование демографического состава всех датасетов.
4. Запрет использования модели в популяциях, не представленных в обучающей выборке, без предварительной валидации.

## 5. Версия данных

### 5.1. Основной датасет: Fundus-AVSeg

| Параметр | Значение |
|----------|----------|
| **Название** | Fundus-AVSeg |
| **Размер** | 100 изображений высокого разрешения |
| **Аннотация** | Пиксельная разметка артерий, вен, капилляров, пересечений |
| **Формат** | RGB-изображения + многоклассовые маски |
| **Разделение** | 3-фолдовая кросс-валидация |

### 5.2. Внешние датасеты (external_datasets/)

Используются исключительно для оценки обобщающей способности модели без дообучения.

| Датасет | Изображений | Разрешение | Особенности |
|---------|-------------|------------|-------------|
| **DRIV-AVE** | 40 | 584×565 | Золотой стандарт; ручная разметка 2 экспертами |
| **STARE** | 20 | 700×605 | Включает патологические случаи |
| **CHASE-AV** | 28 | 999×960 | Педиатрические данные (дети 6–7 лет) |

### 5.3. Предобработка данных

- **Ресайз:** Все изображения приводятся к размеру 512×512 пикселей.
- **Нормализация:** `mean=(0.485, 0.456, 0.406)`, `std=(0.229, 0.224, 0.225)`.
- **Формат масок:** Целочисленные тензоры класса `[0, 4]` для многоклассовой сегментации.

### 5.4. Аугментации (обучающая выборка)

| Аугментация | Параметры |
|-------------|-----------|
| RandomRotate90 | p=0.5 |
| HorizontalFlip | p=0.5 |
| Resize | 512×512, interpolation=BILINEAR / NEAREST для масок |
| Normalize | ImageNet mean/std |

### 5.5. Управление версиями

- Версия датасета фиксируется через хеш-сумму файлов при загрузке.
- Разделение на фолды сохраняется в `dataset/` и не изменяется между экспериментами.
- Все результаты экспериментов привязаны к конкретной версии датасета и конфигурации фолдов.
